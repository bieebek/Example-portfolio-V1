# Bibek Maharjan — IT Portfolio

A cinematic, responsive portfolio focused on IT support, networking, Windows Server, virtualization, and Linux.

## What this site demonstrates

- Accessible, responsive layout built with semantic HTML, CSS, and JavaScript
- Canvas-based network animation and layered 3D interface effects
- Motion controls and reduced-motion support
- Detailed project summaries linked to supporting GitHub documentation
- Clear contact paths for recruiters and hiring managers

## Featured work

- [osTicket Help Desk Lab](https://github.com/bieebek/osticket-helpdesk-lab) — ticket intake, triage, SLAs, escalation, and resolution documentation
- [Secure Multi-Site Network Lab](case-studies/secure-multisite-network.md) — OSPF, SSH, AAA, ACLs, VPN concepts, and validation
- [Windows Server Home Lab](https://github.com/bieebek/windows-server-home-lab) — Windows Server 2022, Active Directory, DNS, DHCP, Group Policy, and deployment services

## Run locally

No build step is required. Download the repository and open `index.html` in a modern browser.

## Structure

- `index.html` — portfolio content and semantic layout
- `styles.css` — responsive visual system, 3D scenes, and motion states
- `script.js` — canvas network, scroll effects, interactions, and motion controls
- `case-studies/` — supporting project documentation
